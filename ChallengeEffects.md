## Challenge Effects

Traverse Difficutly low ->  low progress Outcome
this is a short path, a small obstacle so going around or through it not a big challenge but it also does not bring to much progress.

Traverse Difficulty low*X
This is an easy path that is long, so you have to stay in a matching tool mode across several Closes to keep Exhaustion down.

Reveal +X
This means when this is triggered by overcoming a challenge you See more but it also can effect you, commonly found as effect on challenges

Scout X
 this is an act of safely seeing what is ahead without being effect by its effects, rarely found on challenges, more typical on tool cards where example a spaying class is used to see more.
