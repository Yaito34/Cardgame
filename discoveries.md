# Discoveries

Two systems:

1. **Discovery Book** (`discovery-book.md`) — **transitions** between Travel Book Areas. Search an Area (Discover Difficulty), then copy both end-names into **Leads to**.
2. **Zone Treasure** (`CurrentRulesDesign.md` · Discovery) — **Search** puts the challenge on a Search pile; at stretch end **claim** that Zone’s **Recipe/Tool** card if unclaimed (**no roll**; rarely Lore / a sellable relic). Tick printed Challenge + Action boxes to assemble (**Count** extra overcomes = extra ticks). These do **not** unlock stairs or Areas.

**Playtest:** Ruined Castle treats every transition as already discovered. Ignore Discovery Book searches; use the names already printed in `TravelBook.md`. Search-pile Treasure is claimed at stretch end with no roll.

| Find | What it is now |
|---|---|
| Discovery Book pages | Stair / door names + destination `P#` (see `discovery-book.md`) |
| `Find Discovery T0X` | This Zone’s Recipe/Tool (or Lore) packet card |

Old atlas keys **F1–F4** are unused in the current keep. Stay lines that still say `Find F1` should be retargeted to a **T0X** packet card.
